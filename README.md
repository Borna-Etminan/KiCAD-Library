## [📲 RF_Module_RXC6](https://github.com/Borna-Etminan/KiCAD-Library)
This library was created from measurements of the physical module and verified for use in PCB designs. It is intended for projects using common 433 MHz ASK/OOK wireless remote control systems.

### Features
- ✅ Custom schematic symbol
- ✅ Custom PCB footprint
- ✅ Through-hole package
- ✅ 11-pin layout
- ✅ Ready for KiCad 8/9/10
- ✅ Suitable for DIY and commercial PCB projects

### Pinout

| Pin | Name | Description |
|-----:|------|-------------|
| 1 | GND | Ground |
| 2 | VDD | Power Supply |
| 3 | D3 | Data Output 3 |
| 4 | D2 | Data Output 2 |
| 5 | D1 | Data Output 1 |
| 6 | D0 | Data Output 0 |
| 7 | PIN7 | Unknown / Reserved |
| 8 | PIN8 | Unknown / Reserved |
| 9 | LED | LED Output |
| 10 | GND | Ground |
| 11 | ANT | Antenna |

### Notes
- The pin names were taken from the original module.
- The footprint dimensions were created from the physical module and tested in KiCad.
